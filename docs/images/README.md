## Taking Screenshots

**Best Practices:**
- Use 1920x1080 resolution or higher
- Crop to relevant area (don't show entire screen)
- Use PNG format for clarity
- Show Studio Pro with light theme for consistency
- Highlight important UI elements with red boxes or arrows (optional)
